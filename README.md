# Progetto Chatbot - Elettrodomestici su misura

Progetto d'esame che trasforma un problema reale del lavoro in negozio in una soluzione digitale.

### Idea
Lavoro in un negozio di elettrodomestici e ogni giorno i clienti sono confusi davanti a schede tecniche. Ho creato un consulente virtuale che, partendo da un catalogo reale di 20 prodotti  consiglia l'elettrodomestico più adatto alle esigenze.

### Live Demo
👉 https://assistenzacatalogoelettrodomestici.streamlit.app

### Funzionalità
- Chat interattiva con esempi guidati (es. "cerco lavatrice 10kg sotto i 400€")
- Consigli personalizzati basati su 20 prodotti reali
- Interfaccia divisa in Chat + Info negozio (contatti, orari, supporto)
- Memoria conversazione con session_state

### Tecnologie usate

- **Streamlit**
